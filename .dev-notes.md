# Development Notes

## After pulling animation updates

If you encounter `Uncaught TypeError: a[d] is not a function` error:

1. Stop your dev server (Ctrl+C)
2. Clean the cache: `rm -rf .next out node_modules/.cache`
3. Restart dev server: `npm run dev`

This error occurs due to webpack hot reload cache mismatch after major animation refactoring.
The production build works fine.
